💡 Rekomendasi:
• File JSON - Paling mudah untuk transfer antar device
• File TXT - Kompatibel dengan semua aplikasi
• Salin Kode - Untuk transfer cepat via chat/email

⚠️ Pulihkan Data

Pilih file backup atau masukkan kode backup untuk memulihkan data. Perhatian: Ini akan mengganti semua data yang ada saat ini.

File yang didukung: .json, .txt

📖 Cara Sinkronisasi Cross-Platform

  1. 1. Backup: Klik "Buat Backup" dan pilih "Download JSON" (paling mudah)
  2. 2. Transfer: Kirim file via email, WhatsApp, atau simpan di Google Drive
  3. 3. Restore: Di device lain, pilih file backup dan klik "Pulihkan Data"
  4. 4. Verifikasi: Pastikan semua data sudah ter-load dengan benar
